# 单胞融合策略（paper box-cut）

Hu & Bai 论文 Fig.2.6 几何：**8 根扫掠管、无节点球**，RVE 边界为虚拟立方体 **L³ 平面切割**（非球头连接）。

导出入口：`scripts/export_unitcell_paper_box_cut.py`  
实现：`src/export/unitcell_box_cut.py`

种子 STEP 目录：`output/cad/_unitcell_paper_box_cut/unitcell_{variant}_paper_box.step`

---

## 总览（按 Q）

| Q | 变体 | 单胞融合策略 | OCC 方法名 | 备注 |
|---|------|--------------|------------|------|
| **0** | BCC | pipe-first fuse → RVE L³ 相交 | `gmsh_occ_pipe_box_cut` | 直杆，中心可 pipe-first |
| **0.5** | SFBLS | 同上 | `gmsh_occ_pipe_box_cut` | 正弦屈曲，pipe-first 通常成功 |
| **1.0** | SFBLS | **8×1/8 octant 切杆 → 顺序 fuse** | `gmsh_occ_octant_box_cut` | 无节点球；centre chord stub |
| **1.5** | SFBLS | 逐杆 full L³ box-cut → strut merge | `gmsh_occ_per_strut_pipe_box_cut` | pipe-first / 中心球均易失败 |

单胞验收：`fused_volume_count=1`、`step_solidworks_safe=True`；SW 中 **只打开一个 STEP → 一个零件窗口**。

## Q=1 推荐路线（2026-06 固化）

Q=1（**−A_f·sin**，在 `sinusoidal_path_points` 中对 Q=1 取负号）在胞心裸 pipe OCC 融合会丢杆。节点球种子路线已禁用；只用 paper_box / OCP 单胞。

### 核心思路

1. 将单胞视为 **L³ 立方体**，用 **x=0 / y=0 / z=0** 切成 **8 个相等的 1/8 子块（octant）**。
2. 每根杆从中心 `(0,0,0)` 到一个角点，只属于 **包含中心与该角点** 的那一个 octant。
3. **先**对每根杆做 octant 布尔裁剪（**无 centre weld / 无节点球**），**再**把 8 段 **顺序** 融合成 **1 个实体**。
4. 中心平面微重叠 `OCTANT_CENTER_OVERLAP_MM = 0.02` mm（各 bisector 对称 ±overlap/2），供 pairwise fuse 共享薄体积。
5. **胞心几何**：自动融合路径使用 **centre chord stub**（首段弦圆柱 + open-start pipe），**不用** centre path extension（extension 会破坏 x/y/z=0 的 OCC 接触）。
6. **杆端平切（2026-07-17）**：批处理优先 **`centre_stub_corner_ext`** = **仅角端 path 延长** + centre stub。既避免 both_end 的胞心 extension 导致 fuse 失败，又消除杆端尖楔。椭圆用椭圆弦棱柱 stub。
7. **Face-mate（2026-07-19；2026-07-29 调整）**：1×1 单实体 ≠ 阵列可融。~~1×1 ACCEPT 前硬锁~~已取消——pitch=L 邻胞 fuse 改由 **444 / tip-push** 阶段处理；`_seed_face_mate_ok` 仅作阵列诊断。详见 [`param_batch_STEP生成说明.md`](./param_batch_STEP生成说明.md) §3。
8. **枢纽实心（2026-09-15）**：1×1 ACCEPT = **单实体 + tip-sliver + 胞心实心**。`probe_hub_fill`：原点 **±0.02 mm** 立方探针 fill≥0.85，否则 **REJECT hub-void**（±0.3 会被空腔外壁撑满而误过）。
9. **Af≳2.5 centre_stub 补强（2026-09-15）**：大振幅下首弦会穿出八分体 → **`_path_with_octant_safe_centre_chord`** 截断首弦以保住 tip / face-mate；截断后 stub 过短留下胞心空洞。内存 BOP 无法封洞，故在 **STEP 写出并读回后** 条件触发 **`ocp_fill_hub_ball`**（原点、半径=杆半径）；Af=2 枢纽本就实心则不触发。**Q=1 圆杆 `deq=2`** 梯子优先 **`centre_stub_corner_ext`（ext=2.5/3.0）**，`both_end` 仅作后备（枢纽实心但常无 tip-mate）。

### 顺序 fuse 顺序（关键）

固定顺序 **`OCTANT_SEQUENTIAL_FUSE_ORDER = (0, 1, 2, 3, 4, 5, 6, 7)`**（0-based 杆索引；自然序）。

- **2026-07-29**：旧序 `(…, 7, 6)` 在细杆 `deq=1.5` 上前 6 根正常、**step08 并入 idx6 `(-,+,+)` 时枢纽空缺**；改为先 6 后 7（即自然 `0..7`）目视通过。`deq=2` 冒烟仍为单实体 ~382 mm³。
- 更早曾观测到把 `(+,+,+)`（idx7）放最后会静默丢杆——那是旧 path-extension 路径；当前 `centre_stub_corner_ext` + GlueShift 下以细杆目视为准采用 `0..7`。
- 每步校验质量增量，face-only ``fuse`` 静默丢杆会 **fail-fast**。

### 命令

```powershell
# 自动融合（默认 auto：失败时写 8-body compound）
py -3 scripts/export_unitcell_paper_box_cut.py --Q 1.0

# 仅自动融合
py -3 scripts/export_unitcell_paper_box_cut.py --Q 1.0 --q1-mode fuse

# 8 体 compound（centre path extension，SW 手工 Combine）
py -3 scripts/export_unitcell_paper_box_cut.py --Q 1.0 --q1-mode compound
```

质量参考（L=20 mm，d=2 mm，A_f=2 mm）：切后合计 ~382 mm³，融合后 ~381 mm³（~99.8%）。

### 相关 OCC / 文献结论（2026-06 实测）

| 策略 | 结果 | 说明 |
|------|------|------|
| **顺序 fuse + centre stub** | ✅ ~381 mm³ | 默认（非批处理） |
| **OCP GlueShift + centre_stub_corner_ext** | ✅ ~381 mm³ | **批处理优先**（2026-07-17；硬案 both_end 融失败时） |
| 顺序 fuse，无 stub（closed pipe） | ✅ ~381 mm³ | 胞心可能有三角缝隙 |
| 一次性 batch fuse 8 体 | ❌ ~48 mm³ | 只保留 1 根杆 |
| 3 级树 merge（x→y→z） | ❌ ~143 mm³ | extension 时丢杆 3+4、5+6 |
| fragment → unify 全部碎片 | ❌ BRep_API | 53 碎片，无法 unify |
| 向胞心平移 0.05 mm 再 fuse | ❌ step 5 空 | 重叠过大破坏拓扑 |
| x 半胞 batch + 合并 | ❌ x+ 半胞 step 3 空 | 同 face-only 问题 |
| centre path extension + 顺序 fuse | ❌ step 3 不增质量 | extension 破坏 bisector 接触 |
| OpenCASCADE **SetGlue** (GlueFull/GlueShift) | 未暴露 | gmsh Python API 无 glue 选项；理论适用于共面接触加速，需原生 OCC 或未来 gmsh 版本 |
| BooleanFragments 去重共面 | ❌ | 本几何产生 50+ 碎片，batch unify 失败 |

OpenCASCADE 文档建议：共面/贴靠体用 **GlueFull**（层内）+ **GlueShift**（层间）；gmsh 当前仅暴露 `fuse` / `fragment`，Q=1 单胞仍依赖 **顺序 fuse + 质量校验**。

## Q=1 双模式交付

| 模式 | 输出 | 胞心 | 阵列 auto-fuse |
|------|------|------|----------------|
| `fuse` / `auto` | 1 solid STEP | centre chord stub（推荐） | ✅ 可用作 4×4×4 种子 |

## Q=0 / Q=0.5（pipe-first + box-cut）

1. 8 根 pipe sweep，**无** junction spheres  
2. `_occ_fuse_lattice_for_box_cut`（pipe-first pairwise）  
3. 与虚拟 RVE 立方体 **L³** 相交，截断外伸端面  

失败时回退：逐杆 full L³ box-cut + merge。

## Q=1.5（per-strut full box-cut）

pipe-first 与中心球 seed 均不稳定；默认 **逐杆 L³ 切割** 后 batch / pairwise merge。

## Q=1 失败/弃用路线（勿作 paper_box 种子）

| 路线 | 问题 |
|------|------|
| pipe-first + L³ cut | 胞心丢杆（mass ratio ~0.12） |
| fuse-then-cut + centre weld + trim | 胞心仍残留焊球；与论文几何不符 |
| centre-weld + per-strut cut | 质量/STEP 验收不稳定 |

| z 半胞 **平移** 0.01 mm 再 fuse | 产生 `BREP_WITH_VOIDS`，SW 中心多分面 |
| 3 级 octant 树 merge | 见上表；已替换为 sequential |
| fragment 后取 top-8 质量 | 11+ 碎片时选错体 |

## 4×4×4 阵列融合（paper_box）

单胞种子必须是 **1 volume** 的 `unitcell_*_paper_box.step`（Q=1 先完成上一节）。

| 步骤 | 说明 |
|------|------|
| iz=0 | 4×4 单胞 OCC 顺序融合 → `zslab_iz0_4x4_paper_box_fused.step` |
| iz=1..3 | 复制 iz=0（dz=L） |
| 合并 | 4 个 z-slab → **1 solid** `*_paper_box_array.step` |

**批处理硬案（Q=1 hybrid，2026-07-18～19；细杆 2026-08-04 复验）**：分层 / zcopy 会破坏正交接触。优先 **`ocp_noclip_batch64`**：pitch=L 放置 64 胞 → 一次性 GlueShift batch（已验证 `af2q1_deq2_k1` / `…_k1p5` / `…_k2` / `af2q1_deq2p5_k1` / 椭圆 `af2q0p5_deq2_k2` / 细杆 **`af2q1_deq1p5_k1`**）。细杆 1×1 须 **`centre_stub_corner_ext+ext=1.5`**（face-mate）；`both_end+ov=0.05` 虽能做合格 1×1，但 pitch=L OCC 空融（SW Combine 仍可能成功）。裸 place 空融时用 **`ocp_scale*_batch64`**（已验证 `af2q1p5_deq2_k1p5`）。

**Face-mate（2026-07-29）**：1×1 `volume_count==1` 仍可能 pitch=L 不可贴合，但**不再**作为 1×1 ACCEPT 硬锁；对接问题放到 444 / tip-push。`_seed_face_mate_ok` 保留作阵列诊断。详见 [`param_batch_STEP生成说明.md`](./param_batch_STEP生成说明.md) §3。

**本批 16 案实际成功路径（2026-07-24；细杆 2026-08-04 恢复）**：11 案 = face-mate + `noclip_batch64`（含 `af2q1_deq1p5_k1`）；5 案早期 = gmsh / hierarchical / sequential / 整案复用。逐案表 → [`param_batch_STEP生成情况明细.md`](./param_batch_STEP生成情况明细.md) §2。

```powershell
py -3 scripts/run_hu_bai_paper_box_4x4x4_array_fuse.py --Q 1.0
```

输出目录：`output/cad/_paper_box_array_q1p0/`（Q 标签 `1p0` → `_q1p0`）。

**2026-06 验收（Q=1.0）**：`hu_bai_sfbls_af2q1_L20_4x4x4_paper_box_array.step` — `fused_volume_count=1`，`step_solidworks_safe=True`，耗时 ~7 min（layered fuse）。

实现：`src/export/paper_box_array_fuse.py`（`export_paper_box_layered_array_fuse`）。

Legacy：`--auto-only` 一次性 64 胞 OCC（需稳定 1-volume seed）；`--stepwise-only` 输出 compound 供 SW 手工 Combine。

## 外方内圆试点（中心圆柱孔，2026-09）

在 **已融合 1×1 paper-box 单胞** 上，沿压缩轴 **Z** 做一次中心圆柱 `BRepAlgoAPI_Cut`：外轮廓仍为 **L³ 方包络**，内为圆柱通孔。不是柱坐标共形晶格，也不是实心方块挖孔。

| 项 | 约定 |
|----|------|
| 入口 | `scripts/export_unitcell_cyl_hole.py` |
| OCP 辅助 | `ocp_make_cylinder_z` / `ocp_cut_central_cylinder_z`（`src/export/ocp_unitcell_fuse.py`） |
| 输出目录 | `output/cad/_unitcell_cyl_hole/`（**不**写入 verified 批量树） |
| 试点参数 | Q=0、圆杆 `deq=2`、`L=20`；冒烟 `R_hole ∈ {1.2, 3, 4, 5}` mm |
| 连通性 | `L=20,d=2` 时约 **R≤1.2 mm** 仍为单实体；**R≥1.5 mm** 切断 BCC 枢纽 → 多为 8 体（预期，非失败） |
| 阵列 | **本阶段不做 4×4×4**；每胞各挖一孔 ≠ 一根贯通大圆柱 |

```powershell
py -3 scripts/export_unitcell_cyl_hole.py --R-hole-list 1.2 3 4 5 --L 20 --rod-d 2
# 需要强制单实体时：
py -3 scripts/export_unitcell_cyl_hole.py --R-hole 1.2 --require-one-solid
```

## 框域 trimmed 填充（外方内圆框阵列，2026-09）

目标：在 **Ω = 外方棱柱 − 内圆柱** 内用直角周期阵列填充现有 HuBai 单胞，**内部胞几何不翘曲**；仅边界胞被 `Common(Ω)` 裁切。路线对应文献/工业中的 **trimmed lattice**（先周期再 trim），不是柱坐标共形映射。

与上一节区别：圆柱孔试点是「对单个/已融合实体挖孔」；本节是「先定义框域，再阵列填充并裁到域内」。

| 项 | 约定 |
|----|------|
| 入口 | **改参数用** [`scripts/frame_trim_fill_main.py`](../scripts/frame_trim_fill_main.py)；底层 [`scripts/export_frame_trim_fill.py`](../scripts/export_frame_trim_fill.py) |
| 域模块 | `src/export/design_domain.py`（`make_square_minus_cylinder_domain`、`domain_from_step`、`gate_cell_centers`） |
| 输出目录 | `output/cad/_frame_trim_fill/`（**不**进 verified） |
| 默认试点 | `S=80, H=20, R_hole=25, L=20` → 自动 **4×4×1**；Q=0、`deq=2` |
| 阵列层数 | 默认 `NX=NY=round(S/L)`，`NZ=round(H/L)`；非整除可 snap 到 `n*L` |
| `intersect` | L³ 盒与 Ω 有交则保留，再 Common；冒烟 **16 胞 → 1 solid**，质量 ~4476 mm³ |
| `full_only` | 仅 L³ 几乎完全 ⊆ Ω 的胞；冒烟 **4 角胞**（形状完整、互不接触 → 可为多体） |
| 蒙皮封边 | `intersect` 后再 fuse **内圆柱衬 + 外方画框**（默认 `t=2` mm），把拦腰断面藏进壁面；输出 `*_intersect_skin.step`，不改内部胞 |
| 任意轮廓 | `--domain-step path.step` 换掉方−圆域，门控/裁切管线不变（蒙皮仅方−圆） |

```powershell
# 推荐：打开主脚本改顶部参数后运行
py -3 scripts/frame_trim_fill_main.py
# 命令行（可选）
py -3 scripts/export_frame_trim_fill.py --mode intersect --skin-mm 2
```

本阶段不做：共形映射、边界 net-skin、上下盖板、CAE/verified、大 4×4×4 满孔阵列。
