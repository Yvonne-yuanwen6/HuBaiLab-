## 1. 几何与扫参范围

| 参数 | 含义 | 本批取值 |
|------|------|----------|
| Q | 周期因子（四方向） | 0 / 0.5 / 1.0 / 1.5 |
| Af | 杆中心线幅值 | 中心 2 mm；扫参 1、3 mm（仅 Q=1 圆杆） |
| deq | 等面积等效圆径 | 中心 2 mm；扫参 1.5、2.5 mm（仅 Q=1 圆杆） |
| κ (k) | 截面长径/短径；k=1 为圆杆 | 1 / 1.5 / 2；k>1 默认 ellmin（短径∥压缩） |
| L | 单胞边长 | 20 mm |
| 阵列 | — | 4×4×4（整体高 80 mm） |
| 几何族 | — | paper_box（扫掠管 + 虚拟立方体切割，无节点球） |

案数：共 **16** 案（非全因子）  
- 组 A：Af=2、deq=2，Q×k  
- 组 B：围着 AF2Q1 圆杆扫 Af、deq  

命名示例：`af2q1_deq2_k1`、`af2q1_deq2_k1p5`
